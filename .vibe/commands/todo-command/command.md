# Todo Command

**Command:** `/todo`

**Type:** Slash Command (Manual)

**Purpose:** Manage todo items directly in chat

**Location:** `.vibe/commands/todo-command/`

---

## Description

The `/todo` command allows users to manage their todo items directly from the chat interface. This provides a quick way to add, list, complete, and delete todos without navigating through the UI.

---

## Usage

```
/todo <action> [options]
```

### Supported Actions

| Action | Description | Example |
|--------|-------------|---------|
| `add` | Add a new todo | `/todo add Buy milk` |
| `list` | List all todos | `/todo list` |
| `complete` | Mark a todo as completed | `/todo complete 1` |
| `delete` | Delete a todo | `/todo delete 1` |
| `help` | Show help | `/todo help` |

### Examples

```
/todo add Buy groceries
/todo add Finish project documentation --description "Complete the API docs"
/todo list
/todo complete 2
/todo delete 3
```

---

## Arguments

### add
- **title** (required): The title of the todo
- **--description** (optional): Description of the todo
- **--completed** (optional): Initial completion status (default: false)

### list
- **--all** (optional): Show all todos including completed
- **--active** (optional): Show only active todos
- **--completed** (optional): Show only completed todos

### complete
- **id** (required): The ID of the todo to complete

### delete
- **id** (required): The ID of the todo to delete

---

## Integration

This command integrates with the FastAPI backend by making HTTP requests to the `/todos` endpoint.
