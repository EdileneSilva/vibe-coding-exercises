# Docker Command

**Command:** `/docker`

**Type:** Slash Command (Manual)

**Purpose:** Execute Docker operations directly from chat

**Location:** `.vibe/commands/docker-command/`

---

## Description

The `/docker` command allows users to execute common Docker operations directly from the chat interface. This provides a convenient way to manage the Docker containers without leaving the chat.

---

## Usage

```
/docker <action> [options]
```

### Supported Actions

| Action | Description | Example |
|--------|-------------|---------|
| `status` | Show container status | `/docker status` |
| `start` | Start containers | `/docker start` |
| `stop` | Stop containers | `/docker stop` |
| `restart` | Restart containers | `/docker restart` |
| `logs` | Show container logs | `/docker logs api` |
| `ps` | List running containers | `/docker ps` |
| `build` | Build images | `/docker build` |
| `up` | Start services with compose | `/docker up` |
| `down` | Stop services with compose | `/docker down` |
| `help` | Show help | `/docker help` |

### Examples

```
/docker status
/docker start
/docker stop
/docker logs api --follow
/docker ps --all
/docker build --no-cache
/docker up --build -d
/docker down -v
```

---

## Arguments

### status
- No arguments required
- Shows status of all containers defined in docker-compose.yml

### start
- No arguments required
- Starts all containers

### stop
- No arguments required
- Stops all running containers

### restart
- No arguments required
- Restarts all containers

### logs
- **service** (optional): Specific service name (api, web, db)
- **--follow** / **-f** (optional): Follow log output
- **--tail** / **-n** (optional): Number of lines to show (default: 100)

### ps
- **--all** / **-a** (optional): Show all containers (default: only running)

### build
- **--no-cache** (optional): Build without cache
- **--pull** (optional): Always pull base images

### up
- **--build** / **-b** (optional): Build images before starting
- **--detach** / **-d** (optional): Run in background

### down
- **--volumes** / **-v** (optional): Remove named volumes
- **--rmi** (optional): Remove images

## Integration

This command executes Docker CLI commands on the host system. It requires:
- Docker to be installed
- User to have permission to run Docker commands
- docker-compose.yml to be in the current directory
